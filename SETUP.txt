PARAKH v2 - Complete Setup Guide
=================================
From Kaggle training to VS Code dashboard, step by step.


PART A: KAGGLE — RESEARCH-READY TRAINING
=========================================

STEP A1 — Open your existing Kaggle notebook (the one with NIH dataset attached)
  - You already have NIH dataset at /kaggle/input/datasets/organizations/nih-chest-xrays/data
  - GPU T4 should already be enabled

STEP A2 — Copy parakh_research_ready.py content into a new cell
  This script automatically:
    - Audits metadata for shortcut features (View Position, Follow-up #)
    - Detects and removes perceptual duplicate images
    - Creates a 3-way patient-level split (train/val/test) with ZERO overlap assertion
    - Computes normalization statistics from TRAIN set only
    - Runs 5-fold StratifiedGroupKFold cross-validation
    - Calculates bootstrap 95% confidence intervals on AUC
    - Evaluates on a LOCKED test set (never seen during any training)

STEP A3 — Run all cells top to bottom
  Expected training time: ~6-8 hours (5 folds x 12 epochs + final model)
  Expected REALISTIC results after leakage fixes:
    CV AUC:   0.91 - 0.96 (mean +/- std across 5 folds)
    Test AUC: 0.90 - 0.95 (on locked test set)
    These numbers are publishable and defensible.

STEP A4 — Download these 5 files from Kaggle Output panel:
  parakh_weights.pth         <- trained model weights
  parakh_norm_mean.npy       <- normalization mean (train-computed)
  parakh_norm_std.npy        <- normalization std  (train-computed)
  parakh_metadata.json       <- AUC, CI, and norm stats summary
  cv_results.csv             <- per-fold results table for paper

  How to download: Right panel -> Output -> click file -> three dots -> Download

STEP A5 — Place all 5 files into the backend/ folder:
  parakh_v2/
    backend/
      parakh_weights.pth       <- put here
      parakh_norm_mean.npy     <- put here
      parakh_norm_std.npy      <- put here
      parakh_metadata.json     <- put here
      main.py
      requirements.txt

COMMON ERRORS
=============

Error: ModuleNotFoundError: No module named 'timm'
Fix: Make sure your venv is activated before pip install and before uvicorn.

Error: [PARAKH] No weights at ./parakh_weights.pth — DEMO mode
Fix: Download parakh_weights.pth from Kaggle Output and put it in backend/.

Error: CORS error in browser console
Fix: Backend not running or not on port 8000. Check the uvicorn terminal.

Error: npm install fails
Fix: Run node --version. Need Node 18+. Download from nodejs.org.

Error: Gemini LLM API error
Fix: Check GEMINI_API_KEY is set correctly in the terminal where uvicorn runs.
     The system works without it — fallback summary is used instead.

Error: torch install timeout
Fix: Use: pip install torch --index-url https://download.pytorch.org/whl/cpu
     (CPU-only version, smaller and faster to install)


WHAT CHANGED FROM v1 (DATA LEAKAGE FIXES)
==========================================

v1 problem                    v2 fix
-----------------------------------------------------------------------------------------------
Image-level random split      Patient-level 3-way split with zero-overlap assertion
No duplicate check            Perceptual hash duplicate detection + removal
ImageNet normalization        Train-only normalization (computed from actual training images)
Single train/val split        5-fold StratifiedGroupKFold cross-validation
Point AUC only                Bootstrap 95% confidence intervals reported
No metadata audit             View Position + Follow-up + Age distribution check logged
AUC = 1.000 (suspicious)     Expected realistic AUC: 0.91 - 0.96 (publishable)
No locked test set            Separate locked test set (never seen during training/tuning)
